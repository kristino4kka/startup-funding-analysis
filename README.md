# Анализ финансирования стартапов

Учебный проект по исследовательскому анализу данных о стартапах и инвестициях.

## Цель проекта

Изучить рынок венчурного финансирования и определить:

- какие отрасли привлекают больше инвестиций;
- какие типы финансирования наиболее распространены;
- как менялся объём финансирования по годам;
- какие сегменты рынка демонстрируют рост;
- какие направления могут быть перспективны для инвестирования.

## Данные

В проекте используются данные о стартапах:

- информация о компаниях и их отраслях;
- общий объём привлечённых инвестиций;
- типы и раунды финансирования;
- статусы компаний;
- страны, регионы и города;
- данные о возврате инвестиций по годам.

## Основные этапы анализа

1. Загрузка и первичный анализ данных.
2. Обработка пропусков и дубликатов.
3. Приведение данных к нужным типам.
4. Создание новых признаков и группировка отраслей.
5. Поиск и обработка выбросов.
6. Анализ типов и динамики финансирования.
7. Формулировка выводов и рекомендаций.

## Используемые инструменты

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
